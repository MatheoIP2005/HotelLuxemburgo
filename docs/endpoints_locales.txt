HabitacionesPublic
API publica de habitaciones (lookup) para integraciones externas como Booking y diagnostico del front publico. Lista habitaciones fisicas de una sucursal, opcionalmente filtradas por tipo y rango de fechas (con calculo de disponibilidad).
GET
/api/v1/public/sucursales/{sucursalGuid}/habitaciones
Lista las habitaciones fisicas de una sucursal. Si se envia `tipoHabitacionGuid`, filtra por ese tipo. Si se envian `fechaInicio` y `fechaFin`, devuelve solo las disponibles en ese rango (sin solapamiento con reservas activas).

ReservasPublic
API publica de reservas para el marketplace. Permite a un huesped anonimo crear y confirmar una reserva en una unica llamada usando GUIDs (sin exponer IDs internos).
POST
/api/v1/public/reservas
Crea una reserva publica: registra al huesped como cliente, crea la reserva en estado PEN y la confirma a CON. Devuelve la reserva publica sin campos de auditoria ni IDs internos.
